この講座で目指すこと

平均などの要約だけでは分からない「データの姿」を、グラフで納得できる形で知ることが、この講座の芯です。

  1. 平均などの数字だけでは、データの姿は分からない
  2. 表の読み方・作り方を知ると、グラフが読みやすくなる
  3. グラフは「知りたいこと」に合わせて選ぶ
  4. 最後は、自分の気づきをグラフだけで納得させられるようになる

全8コマの構成

コマ テーマ
第1コマ データ可視化（導入編）
第2コマ Python入門
第3コマ データ集め、データ（変数）の尺度
第4コマ 表のいろいろ・表作成
第5コマ グラフのいろいろ・伝わるデザイン・グラフ作成
第6コマ データを眺めて、気づいたことをグラフだけで納得させる（データ分析）
第7コマ 仮説を納得させるグラフを作るためのデータ集め
第8コマ テスト「データを眺めて、気づいたことをグラフで納得させよ」

準備

  • 環境は Thonny（Python本体と編集画面が一緒になった初心者向け無料ソフト）です。インストール方法は第2コマで説明します
  • 実習データは data.zip をダウンロードし、展開して出てくる data フォルダを、講義フォルダの中に code フォルダと並べて置いてください（詳しくは第2コマ）
  • 表とグラフには pandas、日本語表示には matplotlib-fontja を使います。入れ方は第2コマで案内します
